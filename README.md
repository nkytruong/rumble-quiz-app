__Rumble Quiz__ is a multiplayer mobile trivia game. It was built by __Alex Taylor__, __Nikki Truong__, __Rocio Sainz-Maza__ and __Jo Watson__ as the final project of the Northcoders Software Development bootcamp. 

The front-end of the project was built with React Native and Socket.io for real-time matchmaking. The full list of dependencies can be found in the package.json.

The back-end can be found [here](https://github.com/nkytruong/rumble-quiz-server)!

## Running the app locally

1. Download Expo Go on your mobile device for the best user experience: [https://expo.dev/go](https://expo.dev/go)

2. Clone the repo
```
git clone https://github.com/nkytruong/rumble-quiz-app
```

3. Navigate to the directory.

4. Install dependencies:
``` 
npm install
```

5. Launch the app:
```
npm start
```
6. Scan the QR code that appears in the terminal.
